# 恋爱观察室 · 连接自检

作者：**小狗咖啡猫**

打开即检测：网络、各条线路、浏览器版本和设备是否正常。检测完会列出能打开的线路，自己选一条进入；也可以输入任意网址单独检测，结果可一键复制。

在线地址：https://mewocafe.github.io/text/

## 检测的线路

- sidebyside.sidebyside-proxy.workers.dev
- sidebyside.nya.pub
- sidebyside.8bit.ca
- sidebyside.mooo.com
