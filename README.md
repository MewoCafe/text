# 连接自检

打开即检测：网络、各条线路、浏览器版本和设备是否正常，结果可一键复制。

在线地址：https://mewocafe.github.io/text/

检测的线路：
- sidebyside.sidebyside-proxy.workers.dev
- sidebyside.nya.pub
- sidebyside.8bit.ca
- sidebyside.mooo.com

源码在 xinqukuai 仓库的 `新区块/src/diagnose-*`，用 `node build-diagnose.mjs` 生成后复制 `dist/diagnose.html` 为这里的 `index.html`。
